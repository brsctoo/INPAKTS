## Instruções iniciais

1.  Use a função: `devtools::load_all()`

2.  Verificando a estrutura dos arquivos do R: `fs::dir_tree()`

3.  Inicie o dashboard com a função: `run_app()`

4.  Após serem realizadas alterações no código, você deve usar
    `devtools::load_all()` e depois `run_app()` para visualizar as
    alterações feitas no Dashboard.
